# Radar Criminal

Site estático publicado no GitHub Pages: https://talynefigueiredo.github.io

- `posts.json`: decisões publicadas (texto oficial literal + link da fonte oficial).
- `img/<id>.jpg`: imagem ilustrativa de cada decisão (gerada por IA, identificada no site).
- `p/<id>.html`: páginas de compartilhamento (prévia com imagem no WhatsApp), geradas por `build_share.py`.
- `grupo-enviados.json`: controle das decisões já enviadas ao grupo do WhatsApp.

Atualização automática diária por tarefa agendada do Claude.
